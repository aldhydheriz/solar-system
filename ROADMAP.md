- [x] **2.1 Komet Halley + ekor partikel** — orbit eksentrik tinggi, tail `Points` menghadap menjauhi Sun. File baru: `src/comet.ts`. Tes: ekor selalu menjauhi Sun, 60fps.

- [x] **2.3 Rings Uranus/Neptune/Jupiter** — reuse `makeRingTexture()` (`src/planets.ts`). Uranus tegak (ikut axial tilt 97.8°). Tes: terlihat samar, tidak menutupi planet.
- [x] **2.4 Sun shader animasi** — korona noise + sunspot, ganti material statis di `src/sun.ts`. Tes: 60fps di mode High, mati otomatis di mode Low.
- [x] **2.5 Pluto + Charon + Kuiper Belt** — 1 dwarf planet + 1 moon + belt kedua di luar Neptune. Tes: muncul di nav (`0-9` jadi `1-9`?), deep-link `#pluto` jalan.

## Fase 3 — Edukasi & interaktivitas

- [x] **3.1 Real positions mode** — posisi planet pendekatan JPL per tanggal, toggle vs mode artistik sekarang. Tes: tanggal J2000 ≈ posisi referensi ±5°.

- [ ] **3.5 i18n ID/EN** — semua `desc` + UI string bisa ganti bahasa, simpan di `localStorage` kayak settings sekarang. Tes: toggle bahasa tanpa reload 3D scene.
